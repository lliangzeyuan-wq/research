```
怎样让每个模态输出“证据”和“可信度”，而不是简单拼特征或平均概率？
```


本质上只改两处：

1. **每个模态的最后，不再输出 softmax 概率，而是输出“证据”。**
2. **多个模态在“证据 + 不确定性”层面融合，而不是拼特征或平均概率。**

下面按论文原方法说。

## 1. 每个模态怎么输出证据

假设有音频模态和环境模态，分类有 \(K\) 类。

每个模态有自己的编码器：

\[ h_m = Encoder_m(x_m) \]

然后接一个证据头：

\[ e_m = \operatorname{softplus}(W_m h_m) \]

或者像论文一样用 ReLU，关键是输出必须非负。

这个 \(e_m=[e_{m,1},...,e_{m,K}]\) 不是概率，而是：

- 音频模型给每一类积攒了多少证据；
- 证据越大，说明它越支持该类；
- 所有类的证据都少，说明它整体不确定。

再把证据变成 Dirichlet 分布参数：

\[ \alpha_{m,k}=e_{m,k}+1 \]\[ S_m=\sum_{k=1}^{K}\alpha_{m,k} \]

然后得到两类量：

**某类的信念：**

\[ b_{m,k}=\frac{e_{m,k}}{S_m} \]

**整体不确定性：**

\[ u_m=\frac{K}{S_m} \]

它们满足：

\[ u_m+\sum_k b_{m,k}=1 \]

含义很直观：

- 证据很多且集中在一类：\(u_m\) 小；
- 几乎没有证据：\(u_m\) 大；
- 证据分散在多个类：\(u_m\) 也大。

真正用于预测的类别概率是：

\[ p_{m,k}=\frac{\alpha_{m,k}}{S_m} \]

注意：**\(b\) 不是最终概率，\(u\) 也不是普通的置信度。**  
它们分别表示“支持某类的证据质量”和“我不知道”。

最小 PyTorch 写法大概是：

```
class EvidenceHead(nn.Module):
    def __init__(self, dim, num_classes):
        super().__init__()
        self.fc = nn.Linear(dim, num_classes)

    def forward(self, h):
        e = F.softplus(self.fc(h)) + 1e-6

        alpha = e + 1.0
        S = alpha.sum(dim=-1, keepdim=True)

        b = e / S
        u = self.fc.out_features / S

        return e, alpha, b, u
```

## 2. 怎么训练它，而不是只训练分类准确率

普通 softmax 分类只要求“预测对”。  
证据模型还要学会“该说不知道时就说不知道”。

论文用了两部分损失。

第一部分让正确类别获得更多证据：

\[ L_{ace}=\sum_j y_j\big(\psi(S)-\psi(\alpha_j)\big) \]

其中 \(\psi\) 是 digamma 函数。

第二部分防止错误类别也获得很多证据：

\[ L_{kl}=KL\big(Dir(\tilde\alpha)\|Dir(1)\big) \]\[ \tilde\alpha=y+(1-y)\odot\alpha \]

最终每个模态都训练：

\[ L_m=L_{ace}(\alpha_m)+\lambda L_{kl}(\alpha_m) \]

也就是说，每个模态不仅要把类别分对，还要输出合理的不确定性。

## 3. 多模态怎么融合

假设有两个模态：

\[ M_1=(b_1,u_1),\quad M_2=(b_2,u_2) \]

先用 Dempster 规则合并：

\[ C=\sum_{i\neq j} b_{1,i}b_{2,j} \]

这个 \(C\) 表示两个模态的冲突程度。

然后：

\[ b_k=\frac{b_{1,k}b_{2,k}+b_{1,k}u_2+b_{2,k}u_1}{1-C} \]\[ u=\frac{u_1u_2}{1-C} \]

直观理解就是：

- 一个模态很确定，另一个很模糊：最终主要听确定的；
- 两个都确定且一致：最终更确定；
- 两个都确定但冲突：冲突增大，结果变得不确定；
- 两个都不确定：最终也不确定。

如果有三个或更多模态，就两两反复融合。

最后再把融合后的 \(b,u\) 转回 Dirichlet 参数：

\[ S=\frac{K}{u} \]\[ e_k=b_kS \]\[ \alpha_k=e_k+1 \]

最终类别概率：

\[ p_k=\frac{\alpha_k}{S} \]

这样就不是“音频输出 0.8、环境输出 0.6，平均成 0.7”，而是：

> 音频说它掌握多少证据，环境说它掌握多少证据，两者有多少冲突，最后统一成一个证据分布。

## 4. 这对你的猪舍项目怎么落地

可以这样做：

```
音频编码器 → 音频证据头 → e_audio, u_audio
环境编码器 → 环境证据头 → e_env,  u_env
                        ↓
                  Dempster 融合
                        ↓
             最终风险概率 p + 不确定性 u
```

具体建议：

1. **每个模态单独训练证据头**，先保证音频、环境各自能输出合理不确定性。
    
2. **再做融合训练**，让融合结果也参与损失。
    
3. **缺失模态不要直接填 0**。更合理的做法是把它设成“无证据”：
    
    \[ b=0,\quad u=1 \]
    
    这样它融合后不会改变其他模态。
    
4. **加入质量特征**，例如：
    
    - 音频信噪比；
    - 环境传感器缺失率；
    - 数据漂移程度；
    - 时间戳偏差。
    
    让模型学：
    
    \[ h_m=Encoder_m(x_m,q_m) \]
    
    其中 \(q_m\) 是质量特征。这样“证据多少”和“可信度”会随样本质量变化。
    
5. 评估时不要只看 F1，还要看：
    
    - Brier score；
    - ECE；
    - 高不确定性样本的拒答率；
    - 模态丢失时的性能。

最重要的区别可以记成一句话：

> 普通融合是“把答案合起来”；证据融合是“把每个模态掌握的证据和它到底有多确定一起合起来”。
