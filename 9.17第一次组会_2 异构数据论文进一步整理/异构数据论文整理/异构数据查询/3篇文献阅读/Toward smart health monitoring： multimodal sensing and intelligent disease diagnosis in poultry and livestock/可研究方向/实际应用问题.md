```
**10. 做长期现场验证，证明预警真的有用**

这是最难也最有价值的一步。

不能只证明模型准确率高，还要证明：

- 报警是否真的提前？
- 提前了几天？
- 有没有降低死亡率？
- 有没有减少用药量？
- 有没有改善日增重？
- 有没有降低经济损失？
- 误报会不会让工作人员失去信任？

这需要长期、前瞻性、多猪场研究，甚至需要设置对照组或分阶段干预试验。
```


这一节讲的是：

> 模型在论文里准确率高，只能说明它在实验数据上表现好；还要证明拿到猪场后，预警真的能帮人减少损失。

**为什么不能只看准确率**

假设模型判断咳嗽的准确率是 99%，但可能出现：

- 每天误报 20 次，工作人员很快就不看系统了。
- 真正发病时没有报警。
- 报警比人工发现还晚。
- 报警后没有明确处理建议。
- 用了系统后，死亡率、用药量和成本都没有下降。

所以准确率只是第一步，真正的目标是证明整个系统有用。

**需要证明什么**

**1. 报警是否真的提前**

不是问模型能不能识别咳嗽，而是问：

> 系统是否比人工巡查更早发现异常？

比如人工第 5 天才发现，系统第 2 天就报警，说明提前了 3 天。

**2. 提前了几天**

要计算“预警提前量”：

```
提前量 = 确诊或明显发病时间 - 系统首次可靠报警时间
```

如果只提前几个小时，可能没有足够时间采取行动。提前 2 到 7 天才有实际价值。

**3. 有没有降低死亡率**

系统报警后，猪场及时采取措施，死亡猪只是否更少？

例如：

- 没有系统：每批死亡率 5%。
- 使用系统：每批死亡率 3%。

如果其他条件相同，这才说明系统可能有价值。

**4. 有没有减少用药量**

预警更早，可能减少整体治疗，也可能避免不必要的抗生素使用。

需要比较：

- 每头猪的平均用药量。
- 治疗批次数量。
- 抗生素使用天数。
- 耐药性和药物残留风险。

**5. 有没有改善日增重**

疾病会降低采食量和日增重。系统如果提前干预，猪可能恢复得更快。

要看：

- 平均日增重。
- 料肉比。
- 出栏时间。
- 均匀度。

**6. 有没有降低经济损失**

系统不仅要有效，还要值得花钱。

要算：

```
设备成本 + 维护成本 + 人工成本 + API 成本
                对比
减少死亡、减少用药、提高增重带来的收益
```

如果省下来的钱还没有设备成本高，猪场就不会采用。

**7. 误报会不会让工作人员失去信任**

误报就是：

> 系统报警了，但实际没有问题。

如果太多误报，工作人员会：忽略报警、关掉系统、不再检查。

所以还要评价：

- 每天误报多少次。
- 误报集中在哪些时段。
- 哪些猪场、设备或噪声条件容易误报。
- 工作人员是否愿意继续使用。

**“长期、前瞻性、多猪场”是什么意思**

- **长期**：不是只测几天，而是覆盖多个批次、不同季节。
- **前瞻性**：先设定研究方案，再收集未来数据，而不是回头只分析旧数据。
- **多猪场**：检验不同猪场、设备和品种是否都有效。
- **设置对照组**：一部分猪舍使用系统，另一部分暂时不用，比较结果。
- **分阶段干预试验**：不同猪舍在不同时间开始使用系统，比较前后变化。

**可能需要测量的指标**

- 预警提前时间。
- 灵敏度：真正发生问题时，系统报警的比例。
- 误报率：没有问题却报警的比例。
- 漏报率：真正有问题却没报警的比例。
- 死亡率。
- 用药量。
- 日增重。
- 料肉比。
- 经济损失。
- 兽医响应时间。
- 工作人员信任度。

**为什么很难做**

因为猪场不是实验室：

- 每批猪和环境都在变化。
- 季节、通风和饲料都会影响结果。
- 猪场不会轻易配合随机对照试验。
- 不同猪场的管理方式不同。
- 数据缺失和设备故障很常见。
- 伦理上不能为了做实验而故意不治疗病猪。

**本科生可以怎么做**

不一定一上来就做多猪场临床试验，可以先做：

1. 回顾性分析：系统报警比人工发现提前多久。
2. 误报分析：哪些场景最容易误报。
3. 干预响应分析：报警后工作人员有没有采取行动。
4. 观察性研究：比较使用系统前后的死亡率和用药量。
5. 模拟评估：预测不同预警阈值下的收益和成本。

一句话总结：

**模型准确率高，只能证明它会识别；长期现场验证，才能证明它能帮助猪场少死猪、少用药、少损失，而且工作人员愿意长期使用。**
