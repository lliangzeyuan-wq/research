```
**5. 真正融合声音、图像、环境、生产和病原数据**

很多论文说的“多模态”，实际上只是把两个特征向量拼起来。

真正有价值的融合应该做到：

- 声音判断有没有咳嗽。
- 图像判断猪的行为和位置。
- 环境判断空气质量和温度是否异常。
- 生产记录判断采食和生长是否下降。
- 病原检测提供最终标签和解释。

可以研究：

- 分层融合。
- 交叉注意力。
- 概率融合。
- 图神经网络。
- 时序融合。
- 因果融合。

关键不是模态越多越好，而是不同信息要互相校正。
```


这一节的核心意思是：

> 多模态不是“把很多数据硬拼在一起”，而是让不同数据互相解释、互相纠错。

**为什么只拼接不算真正融合**

假设两个模型分别输出：

```
声音：咳嗽概率 90%
温度：异常概率 20%
```

如果只是把两个特征向量拼在一起，模型可能会被声音信息主导，忽略温度。

现实中更合理的判断是：

- 声音说咳嗽，环境正常，可能是个体呼吸道问题。
- 声音说咳嗽，氨气也高，可能是空气刺激。
- 声音说咳嗽，温度升高、采食下降，可能是感染性疾病。
- 麦克风噪声很大，声音数据不可靠，应该更多看环境和行为。

所以真正融合要回答：**当前哪个数据更可信，哪个数据能解释另一个数据。**

**五个模态分别提供什么**

- 声音：有没有咳嗽、尖叫或异常呼吸。
- 图像：猪在哪里、在做什么、是否跛行、采食和活动是否异常。
- 环境：温度、湿度、CO₂、氨气和通风是否异常。
- 生产记录：采食、饮水、日增重和死亡情况。
- 病原检测：qPCR 提供最终标签和病因方向。

它们不是重复记录，而是从不同角度观察同一群猪。

**六个方法的白话解释**

**1. 分层融合**

先在同一层级内融合，再往上融合：

```
多路麦克风 → 声音风险
多路环境传感器 → 环境风险
声音风险 + 环境风险 + 图像风险 → 最终风险
```

这样比一次性把十几路数据混在一起更清楚，也更容易排查错误。

**2. 交叉注意力**

让不同模态互相“提问”：

- 声音模型问温度数据：咳嗽发生时温度是否异常？
- 环境模型问图像数据：空气质量变差时，猪的活动是否下降？
- 图像模型问生产记录：行为异常后，采食量是否下降？

模型会自动学习哪些数据彼此相关。

**3. 概率融合**

每个模态不只是给“是/否”，而是给出概率和置信度：

```
声音：咳嗽概率 80%，置信度 90%
图像：行为异常概率 60%，置信度 70%
环境：空气风险概率 30%，置信度 95%
```

最后综合这些概率和置信度，而不是只拼特征。

**4. 图神经网络**

把猪、栏位、传感器和时间点看成一张关系图：

```
3号栏的猪咳嗽
5号栏也出现咳嗽
风机覆盖两个栏位
空气可能从3号栏流向5号栏
```

这样模型不只看单个样本，还能看空间传播关系。

**5. 时序融合**

疾病不是一瞬间发生的，模型要关注时间顺序：

```
第1天：氨气升高
第2天：夜间咳嗽增加
第3天：采食下降
第4天：qPCR 阳性
```

时序融合就是让模型从变化趋势中判断，而不是只看当前这一秒。

**6. 因果融合**

普通模型只能发现相关：

> 咳嗽增加时，氨气也高。

因果融合进一步研究：

> 氨气升高是否导致了咳嗽？改变通风后，咳嗽是否下降？

这需要结合干预、时间顺序和反事实分析，不能只靠相关性。

**用一个例子总结**

声音发现咳嗽后，不同数据可以提供不同解释：

```
咳嗽 + 氨气高 + 温度正常
→ 更像环境刺激

咳嗽 + 温度高 + 采食下降 + 活动减少
→ 更像疾病风险

咳嗽 + 声音质量差
→ 降低声音权重，切换其他模态
```

所以关键不是“模态越多越好”，而是：

**每个模态都要提供独立信息，并且能在其他模态不可靠时互相校正。**
