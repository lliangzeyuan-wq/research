```
### 2. 一个麦克风录到的是“混音”，不是一头猪的清晰叫声

每个房间只有一个中央麦克风，录到的是整个房间的混合声场，存在几个问题：

- 猪离麦克风越远，声音越弱，可能被背景噪声盖住。
- 猪栏隔板、墙壁和地面会产生反射，造成混响，把短促的咳嗽声“拖尾”。
- 多只猪同时叫时，声音会叠在一起，模型无法知道到底有几只猪在咳。
- 咳嗽、打喷嚏和某些短促叫声本身就很像，容易混淆。

论文的播放校准显示，最远角落的召回率约为 0.85—0.88，说明远处或受遮挡的事件确实可能漏掉。
```

## 问题本质

一句话：**单麦克风录到的是多只猪、风机、人员、反射声混在一起后的“总信号”，空间信息已经丢了。**

可以把它理解成：

```
麦克风录到的声音
= 多只猪的声音混合
+ 风机等背景噪声
+ 距离衰减
+ 房间混响
```

因此会出现四个问题：

1. 远处猪的声音太弱，可能被噪声淹没；
2. 墙壁和地面的反射让短促咳嗽产生“拖尾”；
3. 多只猪同时叫，无法知道有几只、分别在哪里；
4. 咳嗽、喷嚏和短促叫声本身相似，分类边界模糊。

这不是单纯换一个更强的模型就能解决的。**模型不能恢复录音里根本没有记录的声源位置信息。** 所以首先要改任务目标和采集方式。

## 解决方案

|问题|解决思路|能做到什么程度|
|---|---|---|
|距离远、声音弱|每个栏位附近放麦克风；增加麦克风数量；固定增益；做播放校准|提高远场召回，减少漏检|
|房间混响|去混响；训练时加入不同房间脉冲响应；用 onset、包络等鲁棒特征|减轻拖尾，但无法完全消除|
|多只猪重叠叫|多麦克风阵列、波束形成、声源分离；允许窗口有多个标签|改善分离，但真实猪舍很难做到完全分离|
|咳嗽和喷嚏混淆|事件级标注；增加重叠样本；多任务学习；输出不确定度|降低混淆，但需要更细粒度标签|
|不知道声音来自哪里|麦克风阵列做声源定位；音频与视频、栏位信息融合|可定位到栏位，未必能定位到单只猪|
|单麦无法精确计数|把输出改成房间/栏位级“声音强度”“占用率”“异常趋势”|放弃“精确到每头猪次数”的目标|

## 推荐的系统方案

如果研究目标是**房间级预警**：

```
多麦克风录音
→ 噪声检测和事件检测
→ 去混响/增强
→ 多标签声音分类
→ 房间级强度和趋势聚合
→ 输出风险分数和置信度
```

不需要强求每头猪计数，而是输出：

- 咳嗽样声学活动是否升高；
- 升高了多少；
- 持续了多久；
- 模型有多确定；
- 是否伴随环境或行为异常。

如果目标是**栏位级定位**：

需要增加：

- 每栏至少一个麦克风；或
- 一个房间多个同步麦克风组成阵列；
- 波束形成或声源定位算法；
- 音频和视频、栏位信息联合定位。

如果目标是**个体级监测**：

仅靠一个房间麦克风基本做不到，通常还需要：

- 麦克风阵列；
- 猪只佩戴设备或 RFID；
- 音频—视频融合；
- 个体栏位信息或人工观察。

## 具体应该怎么做

1. **采集层**：每个房间布置 3—4 个以上同步麦克风，最好覆盖不同栏位；使用无损录音和统一校准。
2. **前处理层**：先做事件检测，再做降噪、去混响和声源定位，不要无条件切 1 秒窗口。
3. **识别层**：把任务改成多标签分类，允许多个声音同时存在；输出置信度，低置信度时拒答。
4. **训练层**：加入不同房间混响、距离衰减、麦克风频响和真实重叠事件的数据增强。
5. **融合层**：音频与视频、环境传感器、栏位信息和时间信息做质量感知融合。
6. **评价层**：用已知位置的播放校准测试远场召回，用人工重叠事件测试分离能力，并做留一房间、留一设备验证。

## 最终结论

**如果只要房间级异常预警，单麦方案可以作为粗粒度指标，但必须降低结论强度，不能声称精确计数或个体诊断。**

**如果要栏位或个体级识别，必须先从硬件上增加麦克风数量、空间覆盖和同步能力，再配合声源分离、定位和多模态融合。**

核心不是“模型不够强”，而是：  
**单麦克风缺少空间信息，任务本身在信息上不充分。**
